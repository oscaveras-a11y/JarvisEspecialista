# Ferramentas

Scripts e utilitários **próprios**, desenvolvidos ao longo da trilha de estudos. Começa enxuto e cresce conforme eu aprendo — cada ferramenta nasce de uma necessidade real de laboratório ou CTF.

## Princípios

- Código próprio, comentado e com um `README` ou cabeçalho explicando uso e limites.
- Finalidade **educacional e defensiva** ou de automação de tarefas legítimas.
- Sem ferramentas ou payloads ofensivos prontos para uso contra terceiros — ver [../docs/etica-e-escopo.md](../docs/etica-e-escopo.md).

## Ideias de primeiras ferramentas

- Organizador/renomeador de evidências de laboratório com hash (integridade).
- Parser de logs para linha do tempo simples.
- Automação de enumeração **em alvos de treino próprios**.
