# Writeups

## O que é um writeup

Um **writeup** é o relato de como você resolveu um desafio (CTF, máquina de treino, laboratório): o caminho do reconhecimento até a solução, o raciocínio e o que aprendeu. É a peça central de um portfólio — mostra **como você pensa**, não só o resultado.

## Como organizar

- Um arquivo por desafio, com nome claro: `thm-blue.md`, `htb-lame.md`, `vulnhub-kioptrix.md`.
- Use sempre o modelo [_template.md](_template.md) para manter padrão.
- **Só** desafios de ambientes de treino ou autorizados (ver [../docs/etica-e-escopo.md](../docs/etica-e-escopo.md)).
- Nunca inclua dados reais de terceiros, flags de competições ativas que proíbam divulgação, ou credenciais.

## Boas práticas

- Explique o **porquê** de cada passo, não só o comando.
- Inclua o aprendizado no fim — é o que mais importa para quem lê.
- Capturas de tela ajudam, mas descreva em texto para quem não puder vê-las.
